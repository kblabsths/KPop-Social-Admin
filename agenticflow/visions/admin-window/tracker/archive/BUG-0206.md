# RESOLUTION LATENCY renders three zeros and a dash over a window that holds nothing, directly under the panel BUG-0203 just fixed

## Description
The sibling half of BUG-0203, on the panel directly below it, on the same page,
in the same viewport, over the same table — still reachable on staging today.

**Expected** — LOOK_AND_FEEL -> The Feel -> Interaction principles -> Zeroes:
"a zero states what it excludes whenever the excluded set is not empty ... and
never stands bare beside the rows it silently drops." BUG-0203 settled what a
gauge panel does about that: at a counted zero the four figures give way to the
panel's own Empty state, built from the `EmptyWords` it already composes.

**Found** — `src/components/cycles/latency.tsx:30-37` composes exactly those
words (`nothing = latency.applies === 0 && latency.verdictUnsets === 0`,
holds: "decisions in this window", filledBy: "The resolver applies a claim to
canonical, ...") and hands them ONLY to its `Distribution` and its
`TrendTable` (lines 78-119). The four `GaugeCard`s above them
(`src/components/cycles/latency.tsx:45-77`) render regardless.
