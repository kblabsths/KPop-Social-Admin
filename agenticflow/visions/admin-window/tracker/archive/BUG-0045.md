# Sources and Claims render an internal factory ticket id in product copy, and 'stuck_patterndial' has no space

## Description
Found on the M1 endgame designer walk (2026-09-03), walk instance :8771 against staging, 1440x900. Two defects in one sentence, plus its twin on a second page.

**On `/sources`, below the awaiting-row trend, the app renders:**

    No threshold line is drawn. The per-source stuck_patterndial lives only in the
    scraper repo's source registry, and where Admin may read it is an open question
    (admin-window/TASK-0024) — so no default is substituted here.

**On `/claims` (and the standing-disagreements tab), the app renders:**

    ...stuck-pattern dial is a source-registry value only the scraper repo holds, and
    where Admin may read it is an open question (admin-window/TASK-0024). No default
    is substituted here.

1. **`admin-window/TASK-0024` is a build-tracker ticket id, and it is on screen in the product**, on two of the six pages. The Voice register is "the pipeline's engineer reading you its own logbook" — the pipeline's logbook, not the factory's. The operator has no `/agenticflow` to open, the id will outlive the ticket, and it tells him nothing he can act on. The rest of that sentence already says the true and useful thing ("the dial lives only in the scraper repo's source registry, and no default is substituted here"); the id adds only provenance for a decision made off-screen. Confirmed rendered, not merely in a comment: 2 occurrences in the delivered HTML of `/sources`, 2 of `/claims`, 2 of `/claims?tab=standing`.

2. **`stuck_patterndial`** — on `/sources` the mono `<span>stuck_pattern</span>` is followed immediately by `dial lives only...` with no separating space, so the screen reads `stuck_patterndial` as one word. `/claims` writes the same concept as `stuck-pattern dial`, correctly spaced and not in mono — so the two pages also spell the same dial two ways.

Evidence: `agenticflow/tracker/evidence/designer-walk-m1/sources-light.png` (the sentence, mid-page), `claims-light.png`, `claims-standing-light.png`.

**What this adds that its siblings do not.** BUG-0041 changes how many claim ROWS render; BUG-0043 changes what a SOURCE is called. This one changes two prose sentences and nothing structural — no row count, no label, no link. All three touch `src/app/claims/page.tsx` in different hunks.

## Acceptance criteria
No page of the running app renders a factory ticket id. A scan of the delivered HTML of all six pages plus both claims tabs for `admin-window/` and for `TASK-` finds zero occurrences. What replaces it says the same operational fact in the app's voice, without pointing at a tracker.

`stuck_pattern` renders as its own word with a space before `dial`, and the two pages spell the dial the same way as each other — Voice bar 5 (machine identifiers verbatim in mono) decides which spelling.

**Third site, added 2026-09-03 from the user-sim walk.** On `/cycles`, below the runs table, the delivered HTML reads `<span>source</span>is the run’s own text` — the screen says **`sourceis`**. The source line already contains the space (`src/app/cycles/page.tsx:1003`: `</span> is the run&rsquo;s`), so the eye test on the file says there is no bug; JSX drops that leading space at build time and only the RENDERED string shows it. Fix it the way the same file already fixes its neighbour two lines up — an explicit `{" "}` — and prove it against rendered markup, never against the source line.

The delivered HTML of `/cycles`, `/sources` and `/claims` contains no run-together word: no `sourceis`, no `stuck_patterndial`, and no other `</span>` immediately followed by a letter where a space was intended.

Comments in `src/` may keep citing the ticket; this is about rendered strings only.

`tests/offline/sources/page.test.ts`, `tests/offline/claims/page.test.ts` and `tests/offline/cycles/page.test.ts` each assert the rendered markup contains no `admin-window/`, no `stuck_patterndial` and no `sourceis`.

Human-check: read the sentence under the awaiting-row trend, and the sentence under the runs table, aloud — each is a sentence an engineer would say, with no ticket number and no run-together words. (human-checkable)
