# Absence renders three different ways: a helper-produced dash is primary ink, and a falsy cell body is blank

## Description
TASK-0004 seeds nullDash() so absence looks identical everywhere (src/lib/format.ts docstring), and LOOK_AND_FEEL (Data table) says: "A null renders as `—` in disabled-gray — never blank, never `null`, `N/A` or `none`." The delivered primitives disagree with themselves in three reachable ways. All three are pinned it.fails in tests/offline/ui/primitives.test.ts (describe: "absence, across the format helpers and the primitives"); drop the .fails when they pass.

REPRO 1 — a helper-produced dash is primary ink, beside a raw-null dash that is disabled-gray, in the SAME ROW.
  Render DataTable with rows [{n: null, at: null}] and four columns:
    cell: (r) => r.n            -> <td class="type-data px-2 py-1.5 text-ink"><span class="text-ink-disabled" aria-label="no value">—</span></td>
    cell: (r) => count(r.n)     -> <td class="type-data px-2 py-1.5 text-ink">—</td>
    cell: (r) => relativeAge(r.at).text -> <td class="type-data px-2 py-1.5 text-ink">—</td>
    cell: (r) => absoluteUtc(r.at)      -> <td class="type-data px-2 py-1.5 text-ink">—</td>
  Expected: all four em dashes in disabled-gray (LOOK_AND_FEEL; TASK-0004 item 6).
  Found: only the first is; the other three inherit the cell's text-ink.
  Cause: src/lib/format.ts:47 (absoluteUtc), :68 (relativeAge) and :88 (count) return the bare EM_DASH string, while src/components/ui/data-table.tsx:141 substitutes nullDash() only for null | undefined | "". Two mechanisms for one job, disagreeing. Every table with a nullable count or timestamp column hits this — which is Sources, Claims, and Cycles & runs.

REPRO 2 — a falsy cell body renders a BLANK cell.
  Render DataTable with rows [{flagged: false}] and cell: (r) => r.flagged && "yes" (the standard React idiom; Column.cell is typed ReactNode, which includes false).
  Expected: the em dash in disabled-gray — "never blank".
  Found: <td class="type-data px-2 py-1.5 text-ink"></td>, empty.
  Cause: the same guard at src/components/ui/data-table.tsx:141 does not treat false (or true) as absent.

REPRO 3 — StatCard shows a non-finite figure in primary ink.
  render(h(StatCard, {label: "runs", value: Number.NaN}))
  Expected: the same dash a null figure gets — src/components/ui/stat-card.tsx renders nullDash() for value === null.
  Found: <span class="type-figure text-ink">—</span>, because count(NaN) returns the bare EM_DASH string (src/lib/format.ts:88) and StatCard passes a number straight to count().

Fix direction is the architect's, not mine, but the hole is that the em dash exists in two forms (a string from the helpers, an element from nullDash) and only one of them carries the colour. Whichever way it closes, the invariant to restore is: one absence, one rendering, decided once here so eight pages do not each decide it.
