# Cross-page proofs: graceful absence on all six pages, in_window nowhere, auth on every route, zero residue

## Description
Module: the test tree only — **this ticket adds no product code.** If a page fails one of these proofs, the fix is a BUG on that page's ticket, not a patch from here. Authority: acceptance tests 9, 12, 3 and 13; M1 EC11, EC12, EC5, EC13; SPEC F2.

Four cross-page proofs no single page ticket can carry:

1. **Graceful absence, every page** (test 9): with a stub client that answers every read with the table-not-in-schema-cache error, each of Dashboard, Queues, Claims, Sources, Cycles & runs and Browse renders its **not-provisioned state naming the missing table**, throws nothing, and leaves the rest of the app working. Zero unhandled errors. Add the review-item detail and the record page to the same sweep.
2. **`in_window` nowhere** (test 3): render every page and every filter option set and assert **zero occurrences** of the string `in_window` in the emitted markup — not as a bucket, not as an empty bucket, not as a filter option, not as a zero.
3. **Auth on every route** (test 12): a route inventory read from `src/app/**` — every `page.tsx` and every `route.ts` except `login`, `api/auth` and `api/health` — with an unauthenticated request to each asserting a redirect to `/login`. **The inventory is derived, not hand-listed**, so a route added later cannot escape it. Plus the client-bundle scan: no service-role material in anything `.next` emits for the client (assert on the NAME and on key shape; never print a value).
4. **Zero residue** (test 13): a live-marked sweep asserting staging carries no campaign leftovers — the values the edit-surface live test touched are back to what they were, and no row the campaign created remains. It runs last and is the milestone's closing evidence.

Nothing here weakens a page: a page that cannot pass proof 1 or 2 gets a BUG, and the proof stays as written.

## Acceptance criteria
[tests 9, 12, 3, 13; EC11, EC12, EC5, EC13] The absence sweep covers all six pages plus the two dynamic routes and passes with zero unhandled errors. The route inventory is derived from the filesystem, covers every page and route outside the three public paths, and every one redirects an unauthenticated request to `/login`; the client-bundle scan finds no service-role material. The live residue sweep returns zero campaign-written rows. No file under `src/` changed by this ticket.
