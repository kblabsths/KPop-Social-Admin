# Design tokens and the UI primitives every surface is built from

## Description
Module: `src/app/globals.css` (the tokens) and `src/components/ui/` + `src/components/evidence/` (the primitives). Authority: `agenticflow/docs/vision/LOOK_AND_FEEL.md` in full — The Look (palette, typography, spacing, component rules) — and ARCHITECTURE section 7. This is the foundation every user-facing ticket depends on: **builders consume tokens and primitives, never raw values.**

Ships:

1. **Tokens in `src/app/globals.css` as Tailwind 4 `@theme`** — Tailwind 4 is CSS-first; there is no `tailwind.config.js` in this repo and none is added. Encode: the eleven palette jobs with their light and dark values exactly as LOOK_AND_FEEL's table gives them; the five type steps (`figure` 20/24 semibold mono, `title` 14/20 semibold uppercase +0.05em sans, `body` 12/18 sans, `data` 11/16 mono, `micro` 10/14 uppercase +0.05em sans); the spacing scale 2/4/6/8/12/16/24; radius 0 for containers and 4px for controls. Delete the stub `--background`/`--foreground` pair and the `body { font-family: Arial }` rule that currently overrides Geist.
2. **Primitives in `src/components/ui/`**: `Page` (h1 + 16px padding), `Section` (h2), `DataTable` (surface fill, 1px border, chrome header row of `micro` labels, hairline row separators, hover fill, **no zebra striping, no vertical rules**, sortable headers carrying `arrow up`/`arrow down` in accent when active and the neutral glyph when not, a null rendering as an em dash in disabled-gray, horizontal scroll inside its own border), `StatCard` (micro label, `figure` number thousand-separated, at most one `data` sub-line), `Badge` (never interactive, chrome fill, colour only for severity and health), `Chip` (filter chip: active = accent fill + white), `Button` (one primary per screen; secondary = hairline border; destructive = red border and red text, never a red fill; disabled = 50% opacity and **the label does not change**), and the four mandatory states as four named components: `Loading`, `Empty`, `NotProvisioned`, `ErrorLine`.
3. **`src/components/evidence/EvidencePair`** — the app's signature block: contending claims left, the current canonical value as the rightmost card, hairline-separated and visibly labelled as current; every claim card carries value (`data`, primary text) then `source / tier / age` in secondary, in that fixed order; the canonical card adds its provenance line. The anatomy never changes between screens.
4. **`src/components/EditableCell.tsx`** — move the existing `src/app/components/EditableCell.tsx` here and bring it onto the tokens: click to edit, 1px accent border, Enter or blur saves, Escape reverts, a green `data` confirmation beside the field for 1.5s, a red `data` failure line naming the failure with the value reverting. It takes a submit callback as a prop and knows nothing about routes or tables.
5. Every focusable element shows a 2px accent outline at 1px offset on keyboard focus. No `outline: none` anywhere. Motion budget is exactly 120ms colour transitions plus the 1.5s save confirmation — no shimmer, no pulse, no animated counters.

Rules: mono carries every value the database produced, sans carries every word the app wrote. `text-gray-400` on white is banned for anything a person reads to act. Blue is retired. Severity is a colour (`high` amber, `low` gray), never a scale. Red means broken, never unavailable.

Out of scope: any page, any route, any data access. A primitive that imports from `lib/db` is a defect (ARCHITECTURE section 4).

6. **`src/lib/format.ts` — the shared formatting helpers**, seeded here because every page needs them and a helper nobody seeds becomes eight hand-copies that drift: `relativeAge(ts)` ('3d ago', with the absolute value for the title attribute), `absoluteUtc(ts)` ('2026-08-29 04:12 UTC' — the zone stated once in the column header, never a raw ISO string in a scannable column), `count(n)` (thousand-separated), and `nullDash()` (the em dash in disabled-gray — never blank, never `null`, `N/A` or `none`). The primitives use these; pages never re-implement one. Ages are relative, scheduled times are absolute, counts carry their noun (LOOK_AND_FEEL, Voice bar 6).

## Acceptance criteria
Every primitive named above exists in `src/components/ui/` (or `src/components/` for `EditableCell`), is a pure synchronous component taking plain props, and imports nothing from `src/lib/db`. `src/app/globals.css` carries an `@theme` block defining the palette jobs, the five type steps and the spacing scale; the Arial `body` override and the stub background/foreground variables are gone. The four data-surface states are four separate exported components. Offline tests render each primitive to markup and assert the token classes it emits (not the wording). (human-checkable) The rendered look matches LOOK_AND_FEEL's palette, type scale and density in both themes at the milestone-close screenshot review.
