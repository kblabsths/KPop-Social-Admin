# Edit cell shows no way to save: no control, no hint, Enter is undocumented, and blur silently discards what was typed

## Description
EC10 passes on the mechanism — a mapped column edits, the PATCH answers 200 and the value survives a reload — but the operator is never told how to make that happen. Measured 2026-09-03 on the verifier's own production-like instance (next start, port 8781), staging data, cookie-authed, bundled Chromium.

REPRO
1. Open /records/groups/15ff6af9-178a-4f44-ae11-8bdc0c11b296 (group '2Z').
2. Click the short_name cell (accessible name 'short_name of groups', value 'Tuzi').
3. Look for a way to save.

OBSERVED, all four measured:
- The row in edit mode is exactly one bare input and nothing else. Verbatim DOM of the cell:
    <span class="inline-flex flex-wrap items-baseline gap-2"><input aria-label="short_name of groups" class="type-data w-full rounded-control border border-accent bg-surface px-1 py-0.5 text-ink" value="Tuzi"></span>
  No Save, no Cancel, no placeholder, no title, no aria-describedby.
- Entering edit mode adds ZERO text to the page: the set difference of the body text before and after the click is empty (the only change is that 'Tuzi' disappears into the input). No prose anywhere on the page matches /\bEnter\b|\bEsc(ape)?\b/.
- The page has exactly one <button> in edit mode besides the other cells: 'Sign out'. get_by_role('button', name='Save') count = 0.
- Enter DOES commit: PATCH /api/admin/records/groups/<id> -> 200, and the value survives a reload. Escape reverts with no PATCH. Blur (clicking the FIELDS heading) also exits edit mode with NO PATCH — what was typed is thrown away with no warning and no trace.

WHY IT MATTERS. The one interaction M1 ships for the edit surface has no discoverable commit and a silent-discard exit. An operator who types a correction and clicks away loses it; the only thing that saves them is noticing the cell snapped back to the old value. A key that is the sole commit path must be visible, and a discard must say it discarded.

NOT A DUPLICATE of BUG-0052 (record-page empty state points at Browse) or BUG-0053 (event-record PROVENANCE dashes); neither touches the edit control. No open ticket in INDEX.md names the save affordance.

THE WRITE THIS WALK MADE, for the record: groups.short_name on 15ff6af9-178a-4f44-ae11-8bdc0c11b296, original 'Tuzi', set to 'Tuzi VERIFIER', restored to 'Tuzi' the same way; DB re-read confirms 'Tuzi' and updated_at unchanged at 2026-04-06T14:10:47.251155+00:00.
