# The 404 renders as Next's default inside the Frame: system-ui type off the scale, body fill off the palette

## Description
Early walk of M1 (real app, next start on 8771, cookie-authed, 1280x900, light and dark). A signed-in operator who follows a stale bookmark to a retired surface — /analytics, /database, /data-management, all of which the http suite requires to 404 — lands on Next's built-in not-found page, rendered inside the Frame. The sidebar is ours; everything to the right of it belongs to another product. Measured on /analytics (status 404): the two visible strings compute to font-family 'system-ui' at 24px/weight 500 ('404') and 14px/weight 400 ('This page could not be found.'), colour rgb(0,0,0). LOOK_AND_FEEL's type scale is five steps only — 20/14/12/11/10 — in Geist and Geist Mono, at weights 400 and 600; 24px, system-ui and weight 500 are each outside it, and 'The existing app's text-[9px], text-xl and text-2xl do not survive' is the same rule. The page also injects its own stylesheet, 'body{color:#000;background:#fff;margin:0}' with a prefers-color-scheme:dark arm of 'body{color:#fff;background:#000}', which overrides the token layer for the whole document: measured body background rgb(255,255,255) in light (the palette's page fill is #f3f4f6) and rgb(0,0,0) in dark (page is #030712), with ink at pure black/white instead of #1e2939/#e5e7eb. Nothing else in the app uses those values. Voice: 'This page could not be found.' is the framework's string, not the register — it names no fix and offers no way back, against copy bar 3 ('Every error names what failed, then what to do'). There is no src/app/not-found.tsx in the repo, so this is an omission rather than a divergence; provenance checked, the Frame around it is TASK-0005's ticket-bearing work. Evidence: agenticflow/tracker/evidence/designer/notfound-light.png, notfound-dark.png, notfound-detail.png.

## Acceptance criteria
1. A not-found surface exists at src/app/not-found.tsx and is built from the app's own ui primitives, so it inherits the Frame, the page padding and the token layer like every other route.
2. On the 404 route no visible element computes a font-family outside Geist / Geist Mono, a font-size outside 20, 14, 12, 11 and 10 px, or a font-weight outside 400 and 600.
3. The route no longer ships a style that overrides body colour or background: measured document.body background is the page token (#f3f4f6 light, #030712 dark) and body colour is the ink token (#1e2939 / #e5e7eb), the same as on /browse.
4. The copy names what failed and what to do, in the register, with no apology and no framework default string — and the operator can get back to a page that exists without the browser's back button.
5. tests/offline/shell covers the route: the not-found surface renders inside the Frame and carries no hard-coded hex or off-scale type utility.
Human-check: at 1280 wide, in light and dark, /analytics reads as a page of this app — same background as every other page, Geist type, the sidebar still meaningful — not a framework error screen bolted beside it. (human-checkable)
