# The verdict log as a tab on Queues, newest first, honest when the table is absent

## Description
**SPEC F13.** `verdicts` renders newest first — spec §7 makes it "the one record of every admin data action" and VISION makes it a success criterion.

**It is a TAB, not a seventh page.** VISION names six pages and this campaign does not add one. The log lives as a tab on **Queues** — the surface whose items it settles — reached by a URL facet, exactly the way the standing-disagreements subset lives as its own tab on Claims. That precedent shipped in M1 and is the rendering to copy (`src/components/claims/tabs.tsx`). The sidebar still holds exactly six links at the M2 close; a ticket that adds a seventh is wrong. **State lives in the URL** (§5): the tab is a `searchParams` value, not client state a reload forgets.

**What it renders**, one row per `verdicts` row, newest first: `actor`, `action` (verbatim in mono — §11, never prettified), the item settled **as a link** (nothing on an override — `review_item_id` is null there), the observation written **as a link** (nothing on a settle-only verdict — `observation_id` is null there), the `note`, and `created_at` through `lib/format.ts`. **Both nulls are structural, not missing data**: they are how the log distinguishes an override from a settlement and a settle-only verdict from a value-carrying one. Render each as the mandated dash and say ONCE, on the surface, what a dash means there — LESSONS 1, and BUG-0053 is the M1 bug that cost a walk exactly this.

**The read** goes in `src/lib/db/verdict.ts` beside the call seam (one module owns this object): a **named window** — newest first, an explicit limit, the window stated on the surface — never a complete-read claim about a growing log (§4.3, LESSONS 2). **The window rule applies whole** (DECISIONS 2026-09-04): the tab publishes its window line when the read RETURNED, with rows or with none, and drops the line whole when the read was refused, absent, or never made. That rule is graded once for every surface at once in `tests/offline/absence/pages.test.ts` — inherit it, do not restate it in a docstring.

**Absence is the normal case.** `verdicts` does not exist on staging and will not until Ben installs the handoff. The tab renders `data-state="not_provisioned"` naming `verdicts`, the page answers 200, nothing throws, and **the live parity oracle asserts the not-provisioned STATE rather than comparing a count** — an oracle that asserts a number against a table that does not exist is the M1 bug class that cost six chained tickets (DECISIONS 2026-09-02: a live oracle names the page's state kind before it compares a number, `error` is always a FAIL, and `empty` is a pass with a real 0).

**The oracle addresses its surface by `data-surface`, never by position** (§10, common violations 7 and 8), and counts the SAME narrowing the tab renders — the window's count, not the table's.

**No dial, no gauge, no threshold line** on this surface: it is a log. The gauges' string set appears nowhere on it (M2.md: nothing in M2 renders, reads or hand-copies a dial).

## Acceptance criteria
1. The sidebar holds exactly six links, unchanged from M1; the verdict log is reachable only as a URL facet of `/queues`, and no new top-level route serves it. Asserted by the shell suite and by the route derivation the http suite already does.
2. With `verdicts` ABSENT (staging today): the tab renders `data-state="not_provisioned"` naming `verdicts`, the page answers 200, zero page errors, no window line is published for the unmade read, and the live oracle asserts the not-provisioned STATE rather than comparing a count.
3. With `verdicts` present (fixture): rows render newest first carrying actor, action, item link, observation link, note and time; the window line is published with the window's own held count, including when the read returned zero rows (`data-window-held="0"` plus the labelled empty state — both, together).
4. A null `review_item_id` and a null `observation_id` each render the mandated dash with no qualifier, and ONE line on the surface says what a dash means there.
5. `action` renders verbatim in mono for all eight values of `VERDICT_ACTIONS`, iterated from the constant rather than a hand-written list.
6. The live oracle names its surface with `data-surface` (never `nth-of-type`) and counts the same narrowing the tab renders.
7. Zero dial, gauge or threshold rendering on this surface; the gauge components' own string set appears nowhere in it.
8. `npm run lint`, `tsc --noEmit`, the targeted offline files and the Queues live suite are green.
