- The shim [web-sourced: https://raw.githubusercontent.com/railwayapp/cli/master/npm-install/postinstall.js] fetches a per-platform tar.gz built from a URL template (older manifests spell the pattern out: "https://github.com/railwayapp/cli/releases/download/v{{version}}/railway_{{version}}_{{platform}}_{{arch}}.tar.gz"), unpacks it, and checks the binary exists. It performs NO checksum and NO signature verification, and does not execute what it downloaded. That is the industry-normal esbuild-shaped pattern, but state it plainly: installing this package executes a network fetch at install time and trusts GitHub Releases as the integrity boundary.
