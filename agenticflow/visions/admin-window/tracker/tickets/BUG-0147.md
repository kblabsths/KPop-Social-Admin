# /cycles spells a raw ?cycle= into the app's own sentence, so a bidi control in the URL reverses the page's paragraph

## Description
Found attacking admin-window/BUG-0146 on the landed run branch (a14dcc6). BUG-0146 closed the PADDED route to this sentence and named this hole explicitly as outside its own scope ("NOT part of this ticket ... fixing the denial removes the padded route to it but not `?cycle=<U+202E>not-a-uuid`"). No open ticket carries it; BUG-0137 answered the same harm on `/claims`' dropped-parameter line only.

Expected (ARCHITECTURE.md §7, the rule earned by BUG-0123 -> BUG-0127 -> BUG-0136 -> BUG-0137): "Text this app did not author never sits inside a sentence this app wrote" — foreign text reaches app prose either THROUGH AN ALLOWLIST (`/claims` spells a URL key only if it matches `^[A-Za-z0-9_.-]{1,64}$`, and counts every other without spelling it) or IN ITS OWN BOX (a cell, a row, a `<bdi>`, where a bidi control can only reorder that box's own contents).

Found: `/cycles?cycle=<a value with no canonical form>` spells the raw value into the app's own paragraph inside a plain `<span className="type-data text-ink">` (src/components/cycles/asked-cycle.tsx:76, the `found="false"` arm; the `unchecked` arm at :52-60 has the same shape). A `<span>` is not a bidi isolate, so an unterminated U+202E's scope is the whole paragraph.

MEASURED IN CHROMIUM, production build of the landed tree against staging, QA lane's own bind-probed port 8813 (server killed, port free again), viewport 1440x900, BOTH colour schemes — identical in light and dark. `GET /cycles?cycle=%E2%80%AEnot-a-uuid`, characters of `p[data-cycle-found="false"]` collected by Range rect and sorted by (top, left):

  logical (what the page wrote):
    Cycle <U+202E>not-a-uuid is not among the 200 newest cycles, so it is not in this window - it ran earlier, or no cycle carries that id.
  visual (what the operator reads):
    Cycle .di taht seirrac elcyc on ro ,reilrae nar ti - wodniw siht ni ton si ti os ,selcyc tsewen 002 eht gnoma ton si diuu-a-ton<U+202E>

The app's own 118 characters of prose are reversed by a value that came from the URL. `data-dropped-params` is absent, so the page passes the sentence rather than reporting the facet dropped. The value's own span is 66.00px wide with and without the control, so nothing on screen marks that the sentence was rewritten.

The padded route really is closed and stays closed: `/cycles?cycle=%E2%80%AE<a real cycle id>` renders `data-cycle-asked` = the canonical id, `found="true"`, 1 `tr[data-row-marked="true"]`, and no U+202E anywhere in the markup (same walk, both schemes) — that is BUG-0146 working, and this ticket must not undo it.

Repro (offline, exact, on the landed tree): `./node_modules/.bin/vitest run --project=offline tests/offline/cycles/page.test.ts` with the strict pin "never lets a URL's bidi control into the sentence the page wrote [admin-window/BUG-0147]" flipped from `it.fails(` to a plain `it(`. It fails at the first case with `U+202E U+006E ... : expected true to be false` (watched red before filing, 1 failed | 107 passed). As landed, the pin is `it.fails` and the file is green; the day the hole closes, the XPASS turns the file red and sends the reader here.

Two honest arms, and the ticket should not guess silently:
(a) BUG-0137's answer, which ARCHITECTURE.md §7 states as the rule: spell the asked-for value only when its RAW characters match a renderable allowlist, and otherwise say the page could not read the value back (the `?cycle=` arm has no `withheld` counter to reuse, so this is a wording question the designer may own).
(b) Put the value in a box that isolates it (`<bdi>`), which contains the reorder to the value's own span. Cheaper, but it does not answer the copied-out plain text: the reversal travels with the sentence into a plain-text field where no isolation follows it (BUG-0137's own reasoning for choosing the allowlist).

P3 because the value is attacker-supplied only via a URL the operator themself pastes, on an admin surface behind `admin_allowed_emails` — no privilege boundary is crossed, and nothing is written. It is a truthfulness defect on one sentence, the fourth of its family.

## Acceptance criteria
No value from a ?cycle= URL may put a bidi control (U+202A-U+202E, U+2066-U+2069) into the text of the paragraph /cycles writes about it — in any of AskedCycle's three arms (found, absent, unchecked). Either arm satisfies it: the spelling drops the control (an allowlist, ARCHITECTURE.md §7), or the page spells nothing and reports the facet on the dropped-parameter line. BUG-0146 must stay fixed with it: ?cycle=<U+202E><a real cycle id> keeps answering as the row (found="true", exactly one tr[data-row-marked="true"], data-cycle-asked = the canonical id), and an ordinary unmatched value (?cycle=not-a-uuid) is still spelled in full, so the page does not go quiet instead. Pinned by flipping the strict pin 'never lets a URL's bidi control into the sentence the page wrote [admin-window/BUG-0147]' in tests/offline/cycles/page.test.ts from it.fails( to a plain it(, with every other case in that file still green.
