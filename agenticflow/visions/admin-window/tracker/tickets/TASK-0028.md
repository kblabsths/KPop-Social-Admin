# tsconfig excludes agenticflow: a factory evidence file must not red tsc

## Description
Module: `tsconfig.json`, one line. Authority: this is repo hygiene, not product behaviour — ARCHITECTURE.md section 10 and DECISIONS.md 2026-09-02 ("A ticket that deletes a route must clear `.next` before `tsc`"), same family: `tsc --noEmit` must red on product code and on nothing else.

**The defect, measured 2026-09-02.** `tsconfig.json` includes `**/*.ts` and `**/*.tsx` and excludes only `node_modules` and `scripts`. TypeScript's wildcards skip dot-directories, so `agenticflow/.worktrees/**` and `agenticflow/.venv-tools/**` are already out — but `agenticflow/tracker/evidence/**` is **not**. A `.ts` file written there by any agent is compiled as if it were product source:

```
$ printf 'const x: number = "not a number";\nexport default x;\n' \
    > agenticflow/tracker/evidence/architect/probe/scratch.ts
$ ./node_modules/.bin/tsc --noEmit
agenticflow/tracker/evidence/architect/probe/scratch.ts(1,7): error TS2322: ...
exit 2
```

`agenticflow/tracker/evidence/` is where the kit tells every role to put anything a ticket, handoff or receipt cites — so the repo's own type gate reds on an artefact the factory instructed the agent to write. QA hit it once already. The failure is worst where it is least legible: it lands in someone ELSE's receipt, on a file they did not write, in a directory their ticket does not name.

**The fix.** Add `"agenticflow"` to the `exclude` array. Nothing else changes.

**Measured, both halves, before this ticket was filed** (a probe `tsconfig.probe.json` identical but for the added exclude, deleted afterwards): with the exclude, the broken evidence file above no longer reds `tsc` (exit 0), and `tsc --listFilesOnly | grep -cE '/(src|tests)/'` reports **65 files with the exclude and 65 without** — coverage of product code and tests is byte-identical. Nothing under `src/` or `tests/` is lost.

Do not "fix" this by dropping `**/*.ts` from `include` or by narrowing `include` to `src`/`tests`: `include` also carries `.next/types/**/*.ts` and `.next/dev/types/**/*.ts`, which is what gives pages their typed route params (DECISIONS.md 2026-09-02), plus `next-env.d.ts`, `**/*.mts` (`vitest.config.mts`) and the root config files. `exclude` is the surgical edit.

Out of scope: `.gitignore`, `eslint.config.mjs`, `run.yaml`, and anything under `agenticflow/` itself.

## Acceptance criteria
tsconfig.json's exclude array contains agenticflow. A deliberately ill-typed .ts file written under agenticflow/tracker/evidence/ leaves tsc --noEmit green, and the set of files under src/ and tests/ that tsc compiles is unchanged (65 today). The include array still carries next-env.d.ts, .next/types/**/*.ts, .next/dev/types/**/*.ts and **/*.mts.
