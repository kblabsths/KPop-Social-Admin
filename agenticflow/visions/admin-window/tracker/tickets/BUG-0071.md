Found: agenticflow/docs/vision/STACK.md line 298 (landed f2eb84b, TASK-0036) retires it on the TOOL's arrival instead: 'Until then there is no walk-write surface at all: do a read-and-render walk and say so in your finding. So the two landed docs disagree about the state the repo is in RIGHT NOW, and the one walkers read is the one that removed the surface. Consequence, reachable today with no further change: the M1 endgame walks (designer, user-sims, verifier) have no writable surface, so the save path — the campaign's own core write behaviour, measured landing a 200 and a real column change under BUG-0038 — cannot be walked at all until Ben pastes the DDL, on a schedule the for-human note explicitly calls 'when convenient; nothing is blocked on it'.
