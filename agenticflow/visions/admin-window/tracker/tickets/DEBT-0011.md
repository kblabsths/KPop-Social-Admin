# The mono identifier face is hand-spelled 44 times across 24 files with no shared primitive — the structural root of BUG-0112/0120/0121

## Description
M2 structure walk finding (architect, 2026-09-09), measured on run/admin-window.

§11: 'Machine identifiers render verbatim in mono, never prettified.' The rule is real and the campaign fixed three separate breaches of it in M2 — BUG-0112 (the record page's regime note), BUG-0120 (the record page's empty-state cards), BUG-0121 (the queues detail page's empty-state cards, 'the face BUG-0120 fixed one route over'). Each fix was one hand-typed class pair.

**The measurement.** `grep -rno 'type-data text-ink' src` returns **44 occurrences across 24 files** (counted 2026-09-09). `src/components/ui/` holds fifteen primitives — Page, Section, DataTable, StatCard, Badge, Chip, Button, Loading, Empty, NotProvisioned, ErrorLine, StateOf, WindowLine, MicroLabel, cx — and **not one of them is the identifier**. Two files each grew their own private one instead:

- `src/app/records/[table]/[id]/page.tsx:277` — `function TableName({ config }) { return <span className="type-data text-ink">{config.table}</span>; }`
- `src/app/queues/[reviewItemId]/page.tsx:174` — `function ReviewItems() { return <span className="type-data text-ink">{T.reviewItems}</span>; }`

Byte-identical bodies, different names, two routes, neither reachable from the other. This is exactly Common violations row 9 ('a page helper hand-copied into every page that needs it', promoted 2026-09-03 with `StateOf` ×4 and `WindowLine` ×3) and the reason its promotion note gives: builders in isolated worktrees cannot see each other's code.

**Why it matters beyond tidiness.** A rule spelled as two Tailwind classes at 44 call sites has no place to hold anything else. Three things the campaign has already decided cannot be applied once: the ARCHITECTURE row 15 ruling that foreign text reaches prose through an allowlist or a bidi-isolated box (BUG-0137 — an identifier span is precisely where foreign text lands); `` `unicode-bidi: isolate` ``; and any future rule about wrapping a long unbroken identifier, which BUG-0105 had to solve inside the refusal layout alone.

Scoped `patch` rather than M2: the sweep touches 24 files, several of which BUG-0141 and DEBT-0008 are writing, and it is a mechanical change with no user-visible delta. It should land early in the next milestone, before the next surface adds a 45th hand-spelling.

## Acceptance criteria
1. `src/components/ui/` gains one identifier primitive, exported from the barrel alongside the other fifteen, that renders a machine identifier verbatim in the mono face. It is the only place in `src/` that spells the identifier's class pair.
2. Every call site that renders a machine identifier — a table or view name, a column name, a status/shape/bucket value, an id — imports the primitive. `TableName` and `ReviewItems` are deleted in favour of it.
3. The rendered output is unchanged: the same face, the same ink, verbatim text, no prettification, no uppercasing. Every case BUG-0073, BUG-0112, BUG-0120, BUG-0121 and BUG-0034/43/44/45/49 pinned still holds, graded by the page suites those tickets left behind.
4. The primitive isolates its content for bidi, so an identifier carrying a bidi control cannot reorder the sentence around it — the ARCHITECTURE row 15 rule (BUG-0137) applied once instead of per sentence. A test grades it on two fixtures: one identifier that must be isolated and one ordinary label that must not be touched.
5. Look and feel (LOOK_AND_FEEL, machine identifiers and the Data table rules): the primitive uses the design tokens and never a raw colour or font value; a page of identifiers reads the same in both themes at every supported width; the primitive introduces no new hover-only or pointer-only behaviour.
6. `npm run lint` and `tsc --noEmit` clean; the full offline suite green (this is a shared render primitive touching every page — the §13 targeted-tests exception applies and is claimed here deliberately).
