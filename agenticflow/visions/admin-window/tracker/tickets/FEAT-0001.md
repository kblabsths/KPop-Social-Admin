# Remove the deprecated app and stand up the window shell

## Description
VISION: "The old app is gone. No deprecated surface survives; the sign-in gate, the server-side privilege, and the deploy carry over untouched, and every push stays deployable." SPEC F1. Contracts read 2026-09-01: admin-observability.md §3 (the existing app and what happens to it) and §10 (build mechanics); admin-build.md ground rule "the build owns src/ wholesale". Delete Overview, Analytics, Data Management (including the completeness gap list) and the Database table browser — page, route, and any code only they used. Remove the events editor rather than converting it (§3: events stop being hand-editable until the verdict slice lands). Stand up the navigation for the six pages of §4 — Dashboard, Queues, Claims, Sources, Cycles and runs, Browse — behind the existing NextAuth + admin_allowed_emails gate, which together with the server-side service role and the Railway deploy from main carries over untouched. An old component survives only by re-earning its place.

## Acceptance criteria
M1 EC2, EC12, EC1. Acceptance test 1: `npm run lint` and `npm run build` exit 0 with zero errors. Acceptance test 12: an unauthenticated request to every new page and route redirects to login, and a scan of the built client bundles finds no service-role key. Retired surfaces are gone — `bash -c "test ! -e src/app/analytics && test ! -e src/app/database && test ! -e src/app/data-management"` passes, each retired route returns 404 rather than redirecting to a working page, no navigation entry links one, and no component survives whose only consumer was a retired page. Sign-in, the server-side service-role client, and railway.toml are unchanged in behavior.
