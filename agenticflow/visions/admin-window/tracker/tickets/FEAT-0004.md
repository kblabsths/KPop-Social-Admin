# Queues and the review item rendered, read-only

## Description
VISION: "An investigation never leaves the app: item → its claims → its source and provenance → the event → its edit surface." SPEC F4. Contracts read 2026-09-01: admin-observability.md §4 (Queues) and §6 (a review item rendered — the whole section); resolver.md §11 (review_items). review_items renders as two queues of equal standing — decision and signal — open first, ordered severity then age, settled items browsable, filterable by queue and by shape. The three shapes today classify decision / decision / signal: the data_conflict fact item, the entity_link fact item, and the entity_link source-pattern item. Each shape gets its own detail view over the shared §6 anatomy: what happened (summary sentence, severity, age, folded_count as "asked again xN"); evidence side by side — every evidence observation id resolved to its row (value, source, tier, observed_at, payload link) with the current canonical value of the fact and its provenance beside them; the source-pattern item evidence renders as its folded-record list with the per-source dial beside it. The recommendation slot exists in the layout and renders nothing (its producer is parked). Detail links out to the claims of the item, its source, and the affected record. The close is NOT built in M1 — no settle control, no verdict action, no fixed/wont_fix; those belong to the verdict slice.

## Acceptance criteria
M1 EC6, EC7, EC3, EC4. Acceptance test 4: the three shapes classify decision / decision / signal, and for every shape and queue filter value the returned id set equals the SQL id set. Acceptance test 5: every evidence id renders as its observation row with value, source, tier and observed_at, with the canonical current value and provenance beside them, and each of the three shapes renders its typed view (human-checkable on one close-review screenshot per shape). Acceptance test 2: rendered queue counts equal direct SQL on staging. No settle or verdict control is present anywhere in the UI. The recommendation slot renders nothing. Acceptance test 9: with review_items absent the page returns 200 with its not-provisioned marker. `npm run lint` and `npm run build` exit 0.
