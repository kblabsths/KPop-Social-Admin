# the settle route accepts a text-carrying supply_value for a reference fact — the reference rule is guarded only by the courtesy layer

## Description
**Expected** (FEAT-0010: "The note field … is not the only guard, because FEAT-0009's function raises too. Two guards, on purpose: the form is courtesy, the function is the contract"; `src/lib/verdict/decision.ts` `PAYLOAD_SLOTS`: "a reference chosen by an operator arrives as an `override` from that same record surface, **never as a `supply_value`**"; spec §8 "the apply links rows (`venue_id`, `event_performers`) **instead of writing text**"): a `supply_value` decision whose fact is a `kind: reference` field is refused by `decisionRefusals` — the campaign's ONE pre-database guard — so `POST /api/admin/review-items/{id}/settle` answers 400 and nothing reaches `settle_review_item`.

**Found**: `decisionRefusals` grades it well-formed and the route sends it. admin-window/BUG-0087 put `REFERENCE_FIELDS`/`isReferenceField` in `src/lib/verdict/decision.ts:222-241` and consulted it ONLY from the component that builds the control list (`src/components/review/close/conflict-actions.tsx:129`). `decisionRefusals` (`src/lib/verdict/decision.ts:358-408`) — in the same file, four lines below the predicate — checks the six invariants and never asks the fact's kind: invariant 5 sees exactly one filled slot (`value`), `PAYLOAD_SLOTS.supply_value` allows `value`, and it returns `[]`. The settle route (`src/app/api/admin/review-items/[reviewItemId]/settle/route.ts:129-144`) therefore falls through to the one call. The same hole applies to `override`, whose `PAYLOAD_SLOTS` entry is `["value","ref"]` — the `value` arm of an override on `events.venue` is graded the same way.

So the rule "a reference is never settled with typed text" is enforced in exactly one place, and that place is the list of controls a page chose to render. FEAT-0010's own words for that layer are "courtesy".

- `stub.functionsCalled()` is `["settle_review_item"]` — expected `[]`. The venue NAME is in the `p_decision` argument the function receives, in the `value` slot, for a fact whose canonical column is `venue_id`.
