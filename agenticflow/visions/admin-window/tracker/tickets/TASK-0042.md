# The verdict decision envelope: one typed decision, a pure leaf, the shape the SQL reads

## Description
**Module**: `src/lib/verdict/decision.ts` — a NEW pure domain leaf (ARCHITECTURE §4 rule 7: it imports NOTHING — not `lib/db/**`, not `@supabase/supabase-js`, not `process.env`, not React). It is the first M2 ticket because every other M2 ticket imports it, and builders in isolated worktrees cannot see each other's code (§13.7).

**Why it exists.** SPEC named gap 6: no contract fixes `settle_review_item`'s parameter list, and F9 authors it while F10-F13 call it. If the SQL builder and the UI builders each invent a shape, M2 ships two shapes. This file is the one shape — and the handoff artifact's own offline test imports `VERDICT_ACTIONS` from here and asserts the SQL's `action` CHECK equals it, so the agreement is proved rather than remembered.

**Interface contract — author exactly this, and nothing more:**

    export type VerdictAction =
      | "choose_claimed_value"  // data_conflict: adopt one claimed observation's value
      | "supply_value"          // data_conflict: the operator's own value, admin tier
      | "keep_current"          // data_conflict: canonical stands; the rejections still land
      | "link_entity"           // entity_link fact: confirm the match to an existing entity
      | "settle"                // entity_link fact: leave it held, the claim keeps waiting
      | "fixed"                 // signal disposition
      | "wont_fix"              // signal disposition; the note is REQUIRED
      | "override";             // item-less, from the record surface (null review_item_id)

    export const VERDICT_ACTIONS: readonly VerdictAction[];   // the eight, in this order

    export interface VerdictValue {
      readonly domain: string;      // the REGISTRY domain: "events", "venues"
      readonly entity_id: string;   // the canonical row
      readonly field: string;       // the REGISTRY field name (= the canonical column, except `venue`)
      readonly observation_id: string | null;  // choose_claimed_value: the observation adopted
      readonly value: string | number | boolean | null;  // supply_value / override: the operator's value
      readonly ref: string | null;  // a reference field's chosen entity id, carried as the admin
                                    // source's own external_ref (ARCHITECTURE §9.2)
    }

    export interface VerdictDecision {
      readonly action: VerdictAction;
      readonly review_item_id: string | null;  // null on `override` and ONLY on `override`
      readonly actor: string;                  // the signed-in admin's identity
      readonly note: string | null;            // required, non-blank, on `wont_fix`
      readonly value: VerdictValue | null;
    }

    export function noteRequired(action: VerdictAction): boolean;
    export function decisionRefusals(decision: VerdictDecision): readonly string[];

**The invariants `decisionRefusals` enforces** — each a named string, each tested:
1. `action` is one of the eight.
2. `review_item_id` is null when `action === "override"`, and non-null otherwise.
3. `note` is non-null and non-blank after trim when `noteRequired(action)`.
4. `value` is present on `choose_claimed_value`, `supply_value`, `override`, `link_entity`; null on `keep_current`, `settle`, `fixed`, `wont_fix`.
5. On `choose_claimed_value`, `value.observation_id` is set and `value.value` is null. On a scalar `supply_value` / `override`, `value.value` is set and `value.observation_id` is null. On `link_entity`, and on an `override` of a reference field, `value.ref` is set and `value.value` is null.
6. `actor` is non-blank.

**What this file may NOT carry** (ARCHITECTURE §9.2, each with its reason): no `schema_version` — the registry's, resolved by the FUNCTION; a version number here is scraper registry knowledge re-encoded by hand, which spec §10 calls a flagged gap, not a silent copy. No source name and no tier — the function's own branches. No canonical column name distinct from the registry field. No HTTP, no client, no React.

**Absence is not this file's business.** It is pure; the not-provisioned behaviour lives in the classifier and the call seam. Do not add an "is the function installed" flag here.
