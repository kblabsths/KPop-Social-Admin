# The other half of the fold: six window sentences and four refusal renderings still stand hand-rolled outside the two ui primitives

## Description

Measured on the landed tree at 2115162 (2026-09-04, qa-DEBT-0003), the same class stands in ten more places — the builder's handoff named two of them; the sweep below is the whole set, so the next fold is not scoped from a memory again.

**Window sentences outside `WindowLine` (6).** `grep -rn 'not the whole' src/` plus `grep -rn 'data-window=' src/app/`:

  - src/app/queues/page.tsx:402 — the queue-health gauge states a window in prose and publishes NO `data-window*` hook at all.   - src/app/claims/page.tsx:135 + :568-577 — the LIST window line: its own `<p>`, its own sentence (`windowSentence`), and a different hook set (`data-window-limit`, `data-window-held`, no `-since`/`-until`). It stands two elements away from the folded gauge line on the same page.
  - src/app/cycles/page.tsx:1095 (`data-window="runs"`) and :1361 (`data-window="cycles"`) — two more hand-rolled `<p>`s with the `-limit`/`-held` hook set, on a page this ticket's predecessor rewrote.
  - src/app/browse/page.tsx:151 ('not the whole catalog') and src/components/review/shape-views.tsx:340 — same sentence shape, no hooks.

  So the app has TWO window-line dialects: six lines through the primitive (since/until/truncated) and six hand-rolled (limit/held, or nothing). An oracle cannot ask one question of all of them.

**Refusal rendering outside `StateOf` (4 pages).** /, /queues, /browse and /records/[table]/[id] hand-roll `NotProvisioned`/`ErrorLine` (`LegNote` in browse:83-90 and records:248-256, inline arms in page.tsx:397/407-411/433/436-440, queues:210/222-226/390/392-396), so none of them publishes the `data-not-provisioned` / `data-read-failed` wrapper the four folded pages now do — the hook ARCHITECTURE.md 10 has live oracles read state 3 from state 4 by. **Why one ticket and not two.** One cause (a helper nobody seeded as its own ticket, ARCHITECTURE 13.7), one destination (src/components/ui), and an overlapping set of four page files — splitting it serialises two builders over the same files for no gain.

**Sequencing.** Serial with admin-window/BUG-0077, which settles what `WindowLine`'s `over` prop means; fold /queues onto a contract that is still being argued and it is two rewrites. Do BUG-0077 first.
