# Two gauges on /claims count 'unnamed sources' by two different readings — settled-values still spells its own

## Description
The last copy of a derivation DEBT-0022 already ruled. `src/lib/gauges/settled-values.ts:211` counts a source as unnamed with `if (source === undefined)` — the registry row is MISSING — while its twin gauge `src/lib/gauges/standing-disagreements.ts:166-167` asks the one owner, `isSourceNamed(names, sourceId)` (`src/lib/sources/names.ts`), which answers `false` for a missing row AND for a row whose name has no ink in it, because both put a uuid where a name goes and an operator cannot tell them apart.

It is reachable on screen, not dead code: `src/app/claims/page.tsx:1150-1154` renders `gauge.unnamedSources` from THIS gauge. So the two gauges on the campaign's busiest page can report different counts of "unnamed sources" from the same rows — the exact shape of LESSONS 11 and of the blank-source-name class (BUG-0152/54/56/58/59), which cost five P3 lanes precisely because the rule lived in prose and each surface spelled its own test.

Honest about reach: staging cannot produce the divergence today (`sources.source` is NOT NULL with a shape CHECK, scraper-owned), so nothing is visibly wrong on the live tier — which is why this is P3 and carries no live check. It is filed anyway because it is one line, and because it is the LAST hand-spelling: after it lands, the reading of "did the registry name this source" exists in exactly one module and the class is closed rather than dormant.

## Acceptance criteria
1. `settled-values.ts` asks `isSourceNamed` (via `sourceNamesOf(input.sources)`) instead of `source === undefined`, so both gauges count "unnamed" by the same reading. The label the gauge renders is unchanged — `sourceLabel` already owned it.
2. No other behaviour changes: `unattributed`, `byReason`, `bySource` and the ordering are untouched, and the rendered /claims figures are identical on every fixture where no source name is blank.
3. `tests/offline/gauges/settled-values.test.ts` gains ONE case on both fixtures (LESSONS 8): a `sources` row present with a blank/whitespace name counts as unnamed (it did not before), and a row with a real name does not.
4. The comment says which fact it asks and points at the owner, naming no second spelling (ARCHITECTURE §11, the mechanism clause).
