# LESSONS — the M1 bug classes, for the builder starting a ticket (rewritten whole each close)

1. **Absence is rendered, never blank** (8: BUG-0004/18/19/25/26/27/53/59). Every nullable value goes through `lib/format.ts`'s dash; a dash is secondary ink with no colour and no qualifier unless something was measured; an empty set still renders its labelled figure as a real `0`; a column of dashes carries one line saying what a dash means. Render each page test once against a null/empty fixture — that is how all eight would have died.
2. **A figure reads the same narrowing the surface renders** (7: BUG-0007/09/12/21/22/23/41). Pick the read kind (ARCHITECTURE §4.3: complete-or-refuse vs a named window) before you write the query; count distinct ids, not rows; a filtered surface takes a filtered count, never the fleet's; a read that never happened is an error, not an absence; a null count is a refusal, never a `0`.
3. **A guard proves itself on two fixtures** (10: BUG-0002/03/05/20/28/30 + 29/31/32/33). Any test that scans source or certifies a process ships one input it MUST flag and one it must NOT — a grep guard that never saw a passing spelling passes vacuously; ban the write (`.insert(`, the route, the RPC), never a word the domain owns; and a probe file lands in `src/.probes/`, never where a compiler or a tree-walking test is reading.
4. **`npm test` is not the bar** (5 + DEBT-0002: BUG-0024/37/56/57/58). `ci_command` runs offline+isolated only. If your diff touches a page, a shared render primitive, or a `lib/db` read, run that page's `tests/live/*.live.test.ts` before handoff (`npm run test:live -- <file>`) — offline stubs cannot see a dropped column, a positional selector, or an oracle nobody has ever executed.
5. **A machine identifier is not a label** (5: BUG-0034/43/44/45/49). A uuid on screen gets resolved to the name the rest of the app uses, or a link to the record; a column name is not a table header; §11's "render verbatim in mono" means verbatim — uppercasing `data_conflict` prettifies it wrongly; internal ticket ids never reach product copy.
6. **A command you put in a doc, you have run** (3: BUG-0038/39/51). Paste it into a fresh shell with nothing exported, run it, then write what it actually did — a recipe assembled from other recipes is a claim, not a measurement, and STACK.md's launch lines are what every walker executes verbatim.
