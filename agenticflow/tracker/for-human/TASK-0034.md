## 2. The paste — STAGING project only, never production

```sql
create table if not exists public.walk_sandbox (
  sandbox_id  text primary key,
  label       text not null,
  note        text,
  tally       integer not null default 0,
  is_flagged  boolean not null default false,
  observed_on date,
  created_at  timestamptz not null default now()
);

alter table public.walk_sandbox enable row level security;  -- no policy: service role only
revoke all on table public.walk_sandbox from anon, authenticated;
grant all on table public.walk_sandbox to service_role;

insert into public.walk_sandbox (sandbox_id, label, note, tally, is_flagged, observed_on) values
  ('walk-1', 'First sandbox row',  'A note a walker may rewrite.', 7,  false, '2026-01-15'),
  ('walk-2', 'Second sandbox row', null,                           0,  true,  null),
  ('walk-3', 'Third sandbox row',  'Leave this one alone.',        42, false, '2026-02-20')
on conflict (sandbox_id) do nothing;

notify pgrst, 'reload schema';
```

Why each column: the edit widget is a single text cell, so every type question is
answered by PostgREST on the way in — `label` is text, `note` is the nullable one
(the em-dash absence a walker fills), `tally` is integer coercion, `is_flagged`
is boolean coercion (no catalog table gives us one), `observed_on` is date
coercion and also nullable. `created_at` is set once at seed and is deliberately
**not** in Admin's map, so nothing reads or writes it. The three `not null`
columns are on purpose: clearing one is refused by the database, which is an
error path worth walking.

Two differences from the draft in the earlier version of this note, both
deliberate: `created_at` rather than `updated_at` (nothing updates it, so a
column claiming otherwise would lie), and `2026-02-20` rather than `2026-02-29`
(2026 is not a leap year — the earlier paste would have errored). If you already
pasted the earlier draft, nothing is broken: `create table if not exists` makes
this idempotent, and a column outside the map is never read or written. The seed
values carry no `admin-window` string on purpose — the live residue sweep reads
that string as campaign leftovers.

After the paste, `/records/walk_sandbox/walk-1` on a staging-pointed instance is
the walk surface; before it, that URL draws the ordinary not-provisioned card, and
in production it always will.
